## Professional Summary

I'm an **AWS DevOps Engineer** with 4+ years of experience in CI/CD automation, cloud infrastructure, and containerized environments. I have worked across robotics industrial automation (**Ati Robotics**) and defense (**DRDO/CAIR**) sectors, building reliable pipelines, running Kubernetes workloads, and automating cloud infrastructure on AWS, including air-gapped (offline) CI/CD environments.

### Highlights

- Designed an **Active-Active High Availability** architecture on AWS (EC2, ALB, EFS, RDS, DocumentDB, ElastiCache) with multi-AZ failover.
- Built **Jenkins and GitHub Actions** pipelines that automate Docker builds, version tagging and publishing to Harbor and AWS ECR.
- Ran production **Kubernetes on AWS EKS through Rancher**: deployments, scaling, secrets and SSL certificate renewals.
- Moved hardcoded credentials to **HashiCorp Vault** to improve secret rotation and access control.
- Built **offline CI/CD for ROS2** (Jenkins, Tuleap, local Docker registry, NGINX with internal-CA HTTPS) for a defense research client.
- Monitored infrastructure and pipelines with **Prometheus and Grafana**.

## 💻 About This Website

Built with **Next.js, React, TypeScript, Tailwind CSS and Framer Motion**, deployed on Vercel.

- Animated hero with a DevOps logo and a typing Linux terminal
- Experience timeline with expandable details
- Skills, About, Projects and Contact sections
- Dark and light themes
- All text lives in `src/lib/content/` (experience, skills, projects, contact, hero)

### Run locally

```bash
yarn install
yarn dev        # http://localhost:3000
yarn build      # production build
```

To hide or show the Projects section, change `SHOW_PROJECTS` in `src/lib/utils/config.ts`.
